# 策略周期与持仓时间说明

## 一、当前策略周期

### K线周期
`
当前使用：4小时 (4H)
原因：平衡信号频率和稳定性
`

### 扫描频率
`
建议：每4小时扫描一次
或：每1小时扫描一次（更敏感）
`

---

## 二、持仓时间框架

### 按信号类型分

| 信号类型 | 建议持仓时间 | 说明 |
|----------|--------------|------|
| strong_buy | 3-7天 | 强趋势，持有到趋势减弱 |
| buy | 2-5天 | 标准买入，中等持仓 |
| oversold | 1-3天 | 超卖反弹，快进快出 |
| short | 2-5天 | 做空，等待下跌完成 |

### 按出场条件分

`
止损出场：立即（触发就走）
止盈出场：达到目标价
追踪出场：趋势反转时
RSI出场：RSI>75或<25
阶段出场：威科夫阶段转换
`

## 三、不同周期策略对比

| 周期 | K线 | 持仓时间 | 适合人群 | 优缺点 |
|------|-----|----------|----------|--------|
| 短线 | 15m/1H | 数小时-1天 | 活跃交易者 | 信号多，噪音大 |
| 中线 | 4H/日线 | 3-14天 | 大多数人 | 平衡信号和稳定性 |
| 长线 | 周线/月线 | 数周-数月 | 长期投资者 | 信号少，更可靠 |

### 当前策略：中线为主
`
K线：4小时
持仓：3-7天
止损：ATR*2
止盈：ATR*4
风险回报比：1:2
`

## 五、持仓时间管理规则

### 1. 时间止损
`
规则：持仓超过7天未达止盈，考虑出场
原因：资金效率，避免长期套牢
`

### 2. 浮盈保护
`
持仓3天后：
- 盈利>5%：移动止损到成本价
- 盈利>10%：移动止损到盈利5%位置
- 盈利>20%：移动止损到盈利10%位置
`

### 3. 时间衰减
`
持仓时间越长，仓位应越小：
- 第1-3天：100%仓位
- 第4-7天：50%仓位
- 第7天+：考虑出场
`

## 六、不同交易对的持仓特点

`
特点：波动大，趋势快
建议持仓：2-5天
止盈目标：10-30%
止损：5-10%
`

## 七、实际操作建议

### 入场后
`
第1天：观察，设好止损止盈
第2-3天：如果盈利，考虑移动止损
第4-5天：评估是否继续持有
第7天：未达目标，考虑出场
`

### 出场信号
`
1. 止损触发 → 立即出场
2. 止盈触发 → 立即出场
3. RSI>75 → 考虑出场
4. 趋势反转 → 出场
5. 持仓7天 → 评估出场
`

## 九、如何调整周期

### 如果想要短线
`python
# 修改K线周期
bar = '1H'  # 或 '15m'
# 缩短持仓时间
max_hold_days = 3
# 缩小止盈止损
atr_mult_sl = 1.5
atr_mult_tp = 3
`

### 如果想要长线
`python
# 修改K线周期
bar = '1D'  # 或 '1W'
# 延长持仓时间
max_hold_days = 14
# 放大止盈止损
atr_mult_sl = 3
atr_mult_tp = 6
`
