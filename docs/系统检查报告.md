## 3. 代码逻辑检查

### 得分计算（0-10分）
`
趋势得分（0-3分）：
  价格 > SMA20 且 > SMA50 → +3
  价格 > SMA50 → +2
  价格 > SMA20 → +1

RSI得分（0-2分）：
  RSI < 30 → +2 (超卖)
  RSI < 45 → +2 (RSI低)
  RSI < 65 → +1

成交量得分（0-2分）：
  成交量 > 2倍均量 → +2
  成交量 > 1.3倍均量 → +1

动量得分（0-2分）：
  季度涨幅 > 30% → +2
  季度涨幅 > 15% → +1
`

### 信号生成逻辑
`
strong_buy: 得分>=6 且 阶段=markup 且 30<RSI<70
buy: 得分>=5 且 阶段=markup/markup_weak 且 RSI<65
oversold: RSI<30 且 得分>=3
short: 阶段=markdown 且 RSI>65
hold: 其他情况
`

### 止盈止损计算
`
多头：
  止损 = 当前价 - ATR * 2
  止盈 = 当前价 + ATR * 4
  R:R = 止盈距离 / 止损距离 = 2.0

空头：
  止损 = 当前价 + ATR * 2
  止盈 = 当前价 - ATR * 4
`
