# 仓位管理完整说明

## 一、核心原则

### 1. 风险控制优先
`
单笔最大风险：总资金的 2%
最大持仓数量：5 个
单品种上限：总资金的 20%
总仓位上限：总资金的 80%
`

### 2. 基于风险的仓位计算
`
仓位数量 = 风险金额 / 止损距离
风险金额 = 总资金 × 2%
止损距离 = 入场价 - 止损价（多头）
`

---

## 二、仓位计算公式

### 基础公式
`
仓位数量 = (总资金 × 2%) / (入场价 - 止损价)

示例：
总资金：,000
入场价：.81
止损价：.91

风险金额 = ,000 × 2% = 
止损距离 = .81 - .91 = .90
仓位数量 =  / .90 = 105.26
仓位价值 = 105.26 × .81 = ,243.61

检查：仓位价值 > 总资金×20% = ,000
调整：仓位数量 = ,000 / .81 = 7.2
`

## 三、信号强度调整

### 不同信号的仓位系数

| 信号强度 | 系数 | 说明 |
|----------|------|------|
| weak | 0.5 | 弱信号，半仓 |
| normal | 1.0 | 正常信号，标准仓 |
| strong | 1.5 | 强信号，1.5倍仓 |

### 波动率调整

| ATR占比 | 调整 | 说明 |
|---------|------|------|
| >5% | ×0.7 | 高波动，减仓 |
| 2-5% | ×1.0 | 正常波动 |
| <2% | ×1.2 | 低波动，可加仓 |

---

## 四、仓位管理策略

### 1. 初始建仓
`
信号：strong_buy
仓位：100%（信号强度normal）
止损：ATR×2
止盈：ATR×4
`

### 2. 分批建仓
`
第一批：50%仓位（信号触发时）
第二批：30%仓位（确认突破）
第三批：20%仓位（回调买入）
`

### 3. 加仓规则
`
条件：
- 已有持仓盈利 > 5%
- 趋势继续向上
- 回调到支撑位

加仓量：原仓位的 30-50%
新止损：移动到成本价
`

### 4. 减仓规则
`
条件：
- 盈利达到目标50% → 减仓30%
- 盈利达到目标80% → 减仓50%
- RSI > 70 → 减仓30%
- 趋势减弱 → 减仓50%
`

## 六、风险管理

### 1. 单笔风险
`
最大亏损：总资金的 2%
示例：,000账户，单笔最多亏 
`

### 2. 日风险限额
`
最大日亏损：总资金的 5%
触发后：停止交易，次日再战
`

### 3. 周风险限额
`
最大周亏损：总资金的 10%
触发后：降低仓位50%
`

### 4. 连续亏损处理
`
连续2笔亏损：仓位降低50%
连续3笔亏损：仓位降低75%
连续5笔亏损：停止交易1周
`

## 七、仓位管理模块使用

`python

    total_capital=10000,

    entry_price=277.81,

    entry_price=277.81,

print(pm.get_portfolio_summary())
