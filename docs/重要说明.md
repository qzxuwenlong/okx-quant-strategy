# ⚠️ 重要说明

## 1. OKX 是什么？

**OKX 是加密货币交易所**，不是美股！

| 平台 | 交易品种 | 例子 |
|------|----------|------|
| **OKX** | 加密货币 | BTC、ETH、SOL等 |
| 美股券商 | 美国股票 | AAPL、TSLA、GOOGL等 |

我们这个策略是用于 **加密货币交易** 的，交易对比如：
- BTC/USDT（比特币）
- ETH/USDT（以太坊）
- SOL/USDT（Solana）

---

## 2. 关于 API 密钥

### 监控模式（推荐）
- **不需要 API 密钥**
- 可以获取公开的K线数据
- 用于观察信号，不执行交易

### 交易模式
- **需要 API 密钥**
- 需要在 OKX 官网申请
- 用于实际执行买卖操作

---

## 3. 运行方式

### 方式一：监控模式（无需API密钥）

`ash
python strategy_example.py
`

选择模式 1 (monitor)，可以：
- ✅ 获取实时价格
- ✅ 计算技术指标
- ✅ 生成交易信号
- ❌ 不能执行交易

### 方式二：交易模式（需要API密钥）

1. 先在 OKX 官网获取 API 密钥
2. 编辑 strategy_example.py 填入密钥
3. 运行策略选择模式 3 (live)

## 5. 常见问题

### Q: 为什么会报错 "Invalid OK-ACCESS-KEY"？

A: 因为你在用交易模式但没有配置API密钥。用监控模式就不需要密钥。

### Q: 这个策略能用于美股吗？

A: 不能直接用。这个策略是为加密货币设计的。如果要做美股，需要：
- 换成美股券商API（如 Interactive Brokers、TD Ameritrade）
- 调整策略参数

### Q: 代理怎么配置？

A: 在代码中修改 PROXY 变量：
`python
PROXY = "http://127.0.0.1:7890"  # Clash
# PROXY = "http://127.0.0.1:10809"  # V2Ray
`
