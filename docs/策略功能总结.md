## 📈 策略信号系统

### 买入信号（做多）
`
1. 威科夫突破：上涨阶段 + 放量突破
2. 威科夫回踩：上涨趋势 + 回踩支撑反弹
3. MACD金叉 + RSI超卖反弹
4. CANSLIM筛选通过
5. 欧奈尔顶部形态突破
`

### 卖出信号（平多仓）
`
1. 威科夫派发：派发阶段 + 放量滞涨
2. 价格跌破支撑位
3. RSI超买反转
4. 欧奈尔卖空信号出现
`

### 做空信号（开空仓）
`
1. 欧奈尔卖空信号（头肩顶、双重顶、突破失败）
2. 威科夫下跌阶段 + 放量下跌
3. 价格跌破布林带下轨
4. MACD死叉
`

### 平空仓信号
`
1. 威科夫吸筹阶段
2. 价格突破布林带上轨
3. RSI超卖反弹
`

### 仓位管理
`python
# 基于波动性调整
volatility = df['close'].pct_change().rolling(20).std()
position_size = base_size * (0.02 / volatility)

# 做空仓位减半（风险更大）
if signal == 'short':
    position_size *= 0.5
`

### 止损设置
`python
# 基于ATR
stop_loss = entry_price - (atr * 2)  # 做多
stop_loss = entry_price + (atr * 2)  # 做空

# 固定百分比
stop_loss = entry_price * 0.95  # 做多5%止损
stop_loss = entry_price * 1.05  # 做空5%止损
`

### 止盈设置
`python
# 基于ATR
take_profit = entry_price + (atr * 3)  # 做多
take_profit = entry_price - (atr * 3)  # 做空

# 固定百分比
take_profit = entry_price * 1.10  # 做多10%止盈
