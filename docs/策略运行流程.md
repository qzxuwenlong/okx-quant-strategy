## 二、详细运行流程

### 步骤1：市场扫描

`
获取OKX所有USDT永续合约（约427个）
           ↓
    多线程并发扫描
           ↓
    获取每个币种的4小时K线数据
           ↓
    计算技术指标（SMA、RSI、ATR、成交量）
           ↓
    生成交易信号和得分
`

### 步骤2：信号生成逻辑

`
输入：价格、成交量数据
           ↓
计算指标：
  - SMA50（50日均线）
  - RSI（相对强弱指标）
  - 成交量比率
  - ATR（平均真实波幅）
           ↓
评分系统（0-6分）：
  - 价格 > SMA50      → +3分
  - RSI < 30           → +2分
  - RSI 30-45          → +2分
  - RSI 45-65          → +1分
  - 成交量 > 1.2倍     → +1分
           ↓
信号判断：
  - 得分 >= 5 且 RSI 30-70 → 买入信号
  - 得分 >= 4 且 RSI < 65   → 买入信号
  - 其他                     → 观望
`

### 步骤3：仓位管理

`
输入：入场价、止损价
           ↓
计算风险金额：
  风险金额 = 总资金 × 2%（单笔风险）
           ↓
计算仓位数量：
  仓位数量 = 风险金额 ÷ 止损距离
           ↓
检查上限：
  仓位价值 ≤ 总资金 × 20%（单品种上限）
           ↓
输出：仓位大小
`

### 步骤4：止盈止损设置

`
基于ATR（平均真实波幅）计算：
           ↓
止损 = 入场价 - ATR × 2
止盈 = 入场价 + ATR × 4
           ↓
风险回报比 = 1:2
`

### 步骤5：监控持仓（持续运行模式）

`
每5分钟检查一次持仓
           ↓
检查出场条件：
  - 价格 <= 止损价     → 止损出场
  - 价格 >= 止盈价     → 止盈出场
  - RSI > 75           → 超买出场
           ↓
触发出场 → 记录交易 → 更新资金
`

    def scan(self):
        # 获取所有交易对
        symbols = self.data_manager.get_all_symbols()
        
        # 并发分析
        for symbol in symbols:
            data = self.data_manager.fetch_klines(symbol)
            indicators = self.signal_generator.calculate_indicators(data)
            signal, score = self.signal_generator.generate_signal(indicators)
            
            if signal == 'buy' and score >= 4:

        return results
