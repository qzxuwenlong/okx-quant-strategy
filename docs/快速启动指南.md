# 🚀 快速启动指南

## 第一步：测试代理连接

`ash
# 运行代理测试脚本
python test_proxy_connection.py
`

选择你的代理类型：
- **1** - HTTP代理 (默认端口 7890)
- **2** - SOCKS5代理 (默认端口 1080)
- **3** - 不使用代理
- **4** - 自定义代理地址

---

## 第二步：配置API密钥

编辑 strategy_example.py，修改以下配置：

`python
# API密钥配置
API_KEY = "你的API_KEY"
SECRET = "你的SECRET"
PASSPHRASE = "你的PASSPHRASE"

# 代理配置（选择一个）
PROXY = "http://127.0.0.1:7890"      # HTTP代理
# PROXY = "socks5://127.0.0.1:1080"  # SOCKS5代理
# PROXY = None                        # 不使用代理
`

---

## 第三步：运行策略

`ash

python strategy_example.py
`

选择运行模式：
- **1** - monitor（仅监控，不交易）← 推荐先用这个测试

- **3** - live（实盘交易，谨慎使用）

## 常见问题

### Q1: 代理连接失败怎么办？

检查清单：
1. ✅ 代理软件是否运行（Clash/V2Ray/Shadowsocks等）
2. ✅ 代理端口是否正确
3. ✅ 是否允许局域网连接
4. ✅ 防火墙是否放行

### Q2: 常用代理端口

| 软件 | HTTP端口 | SOCKS5端口 |
|------|----------|------------|
| Clash | 7890 | 7891 |
| V2Ray | 10809 | 10808 |
| Shadowsocks | 1080 | 1080 |

### Q3: 如何获取OKX API密钥？

1. 登录 [OKX官网](https://www.okx.com)
2. 进入 **API管理** 页面
3. 创建新的API密钥
4. 权限选择：**读取 + 交易**
5. 记录 API Key、Secret、Passphrase

### Q4: 模拟环境和实盘的区别

| 特性 | 模拟环境 (sandbox) | 实盘 |
|------|-------------------|------|
| 资金 | 虚拟资金 | 真实资金 |
| 风险 | 无风险 | 有风险 |
| 用途 | 测试策略 | 正式交易 |
