# 🎯 牛熊市判断速查表

## 📊 快速判断方法

### 1. 均线系统（最简单）

| 指标 | 牛市信号 | 熊市信号 |
|------|----------|----------|
| **价格 vs MA20** | 价格 > MA20 | 价格 < MA20 |
| **价格 vs MA50** | 价格 > MA50 | 价格 < MA50 |
| **价格 vs MA200** | 价格 > MA200 | 价格 < MA200 |
| **均线排列** | MA20 > MA50 > MA200 | MA20 < MA50 < MA200 |
| **金叉/死叉** | MA50 上穿 MA200 | MA50 下穿 MA200 |

### 2. RSI 指标

| RSI 值 | 市场状态 | 操作建议 |
|--------|----------|----------|
| **> 70** | 超买/强势 | 谨慎追多，注意回调 |
| **50-70** | 偏多 | 可持有多仓 |
| **30-50** | 偏空 | 可持有空仓 |
| **< 30** | 超卖/弱势 | 谨慎追空，注意反弹 |

### 3. MACD 指标

| 信号 | 牛市信号 | 熊市信号 |
|------|----------|----------|
| **MACD位置** | MACD > 0 | MACD < 0 |
| **金叉/死叉** | MACD 上穿 Signal | MACD 下穿 Signal |
| **柱状图** | 柱状图放大 | 柱状图放大 |
| **零轴上方** | 强势 | - |
| **零轴下方** | - | 弱势 |

### 4. 成交量分析

| 价格变化 | 成交量 | 含义 | 信号 |
|----------|--------|------|------|
| **上涨** | 放大 | 多头强势 | 🔥 强烈看涨 |
| **上涨** | 缩小 | 动能不足 | ⚠️ 弱势看涨 |
| **下跌** | 放大 | 空头强势 | 🔥 强烈看跌 |
| **下跌** | 缩小 | 抛压减弱 | ⚠️ 弱势看跌 |

### 5. 价格结构（威科夫核心）

| 结构 | 牛市结构 | 熊市结构 |
|------|----------|----------|
| **高点** | 更高的高点 (HH) | 更低的高点 (LH) |
| **低点** | 更高的低点 (HL) | 更低的低点 (LL) |
| **趋势** | 上升趋势线 | 下降趋势线 |

## 🚨 注意事项

1. **不要单一指标判断** - 综合多个指标
2. **注意时间周期** - 日线判断大趋势，小时线判断入场时机
3. **成交量确认** - 没有成交量配合的突破要谨慎
4. **背离信号** - 价格与指标背离是重要反转信号
5. **市场环境** - 不同市场环境下指标有效性不同
